CLARK ATM MANAGEMENT — ONE-PAGE SITE

DEPLOY
Upload the contents of this folder to the Apache document root.
Requires PHP 8+ and Apache mod_rewrite. The .htaccess file merely directs
unknown URLs to index.php; route decisions and response codes live in PHP.

FILES
index.php          Routes, redirects, 404 response
home.html          Editable main-page markup
404.html           Branded not-found page
assets/styles.css  Responsive styles
assets/favicon.svg Vector favicon
favicon.ico        Traditional favicon
assets/apple-touch-icon.png  Mobile home-screen icon
